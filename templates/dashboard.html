When to fix the charter

Choose a decision date and the model returns the forecast it made at that moment — fitted only on data before it, with a five-day purge gap. Because the forecast is genuinely out-of-sample the outcome is knowable, so it is shown beside the call rather than hidden.

Control experiment

The Baltic Capesize index is a daily broker survey; panellists anchor on the previous print, so its returns are autocorrelated and genuinely forecastable. BDRY is a liquid, arbitraged ETF over the same underlying. We ran the identical method on it — scoring well there too would mean claiming to beat a futures market, which is a red flag rather than a feature.
